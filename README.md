# DOTPLAN — 自分用タスク＆カレンダー（PWA）

iPhone のホーム画面に追加して、アプリとして使えるWebアプリです。
データは iPhone の中だけに保存され、どこにも送信されません。オフラインでも動きます。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・機能すべて） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | オフライン対応（Service Worker） |
| `icons/` | ホーム画面アイコン |

このフォルダを**丸ごと**ネットに置けば動きます（HTTPS が必要。以下のサービスはどちらも自動で HTTPS）。

---

## 公開方法A：GitHub Pages（おすすめ・無料）

あとで同期機能を足すときも、ここでファイルを更新していくのが楽です。

1. https://github.com でアカウントを作る
2. 右上「＋」→「New repository」
   - Repository name：`dotplan`（好きな名前でOK）
   - Public を選択（※アプリのコードは見えますが、**タスクのデータはあなたのiPhoneの中だけ**なので公開されません）
   - 「Create repository」
3. 「uploading an existing file」をクリック → このフォルダの中身（`index.html`・`manifest.webmanifest`・`sw.js`・`icons` フォルダ）をまとめてドラッグ → 「Commit changes」
4. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」
   - Branch：`main` / `/(root)` →「Save」
5. 1〜2分待つと、同じ画面に `https://ユーザー名.github.io/dotplan/` のURLが出ます

> 学生なら **GitHub Student Developer Pack**（無料）で GitHub Pro が使え、リポジトリを Private にしたまま Pages で公開することもできます。

## 公開方法B：Netlify Drop（いちばん手軽）

1. https://app.netlify.com/drop を開いてログイン（無料アカウント）
2. このフォルダをブラウザにドラッグ＆ドロップ
3. 発行された `https://〇〇.netlify.app` のURLを使う

## iPhone のホーム画面に追加する

1. iPhone の **Safari** で公開したURLを開く
2. 画面下の **共有ボタン**（□に↑）をタップ
3. 「**ホーム画面に追加**」→「追加」
4. ホーム画面の DOTPLAN アイコンから起動すると、全画面のアプリとして動きます

※ 必ずホーム画面のアイコンから使ってください。Safari のタブで開いた場合とホーム画面アプリでは、保存されるデータが別になります。

## 使い方メモ

- **＋ボタン**：タスク／予定を追加（上のスイッチで切り替え）
- **丸をタップ**：タスクを完了／未完了
- **項目をタップ**：編集・削除（削除しても直後なら「元に戻す」可能）
- **週の帯・カレンダーを左右にスワイプ**：前後の週／月へ移動
- **曜日で繰り返し**：追加画面でオンにすると、選んだ曜日に一括で登録（バイトなど）。編集時に「以降の繰り返しにも反映」も可能
- **履歴から入力**：追加画面の「RECENT」をタップすると、よく使うタイトル・時刻・カテゴリがそのまま入る
- **メモ**：下のタブ「メモ」。上の欄に書いて「追加」ですぐ保存。メモからタスクへの変換もできる
- **設定**：「今日」画面右上の歯車。カテゴリ名の変更、バックアップの書き出し・復元

カテゴリは形で見分けます：● 1つ目（初期値「課題」）／○ 2つ目（「バイト」）／■ 3つ目（「個人」）

## バックアップ

設定 →「バックアップを書き出す」で JSON ファイルを「ファイル」アプリや iCloud Drive に保存できます。
機種変更のときは、新しい iPhone で「バックアップから復元」を選んでそのファイルを読み込みます。

## アプリを更新したとき

`index.html` などを差し替えたら、`sw.js` の `VERSION = 'dotplan-v1'` の数字を上げて（`v2` など）一緒にアップロードしてください。
次にアプリを開いたとき（反映されない場合はもう一度開き直したとき）に新しい版になります。

## 今後：iPad などとの同期

データは同期しやすい形（ID・更新時刻・削除フラグ付き）で保存しているので、
Supabase（無料枠あり）のログインと同期を後から追加できます。
